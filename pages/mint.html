Linux Mint Checklist

Desktop-focused Mint hardening. Tap an item to check it off; progress is saved on this device.

Read the README and forensics questions first. Preserve required users, desktop access, packages, services, and scoring tools. Mint editions and versions differ; verify each setting on the image before changing it.

0 of 0 done
  1. Baseline and desktop access
    1. Confirm Mint version, edition, desktop environment, hostname, network configuration, and competition role.
    2. Read the README, forensics tasks, required-user list, and permitted/prohibited software list.
    3. Record the initial configuration and make an approved snapshot or backup if available.
    4. Keep a working local login and do not change display manager or desktop packages without verifying recovery access.
  2. Users, groups, and login
    1. Compare local accounts and groups with competition requirements; investigate unexpected users and UID 0 accounts.
    2. Disable or remove only unauthorized accounts; preserve required team, scoring, and service accounts.
    3. Review sudo group membership and sudoers rules; limit administrative access to approved users.
    4. Set strong passwords for required interactive accounts and review password aging and lockout policy.
    5. Disable automatic login and guest sessions when not required; verify the correct user can still sign in.
  3. Updates and software sources
    1. Use Update Manager or APT to review available security and system updates.
    2. Review update changes and removals; preserve the required desktop environment, drivers, scoring engine, and applications.
    3. Inspect APT sources and additional repositories; remove unauthorized sources and keys.
    4. Do not switch Ubuntu base repositories or upgrade Mint releases during a competition unless explicitly instructed.
    5. Review installed applications, browser extensions, and startup apps against the permitted software list.
  4. Firewall and network sharing
    1. Check firewall status and existing rules; enable the supported firewall only after confirming needed access.
    2. Allow required SSH, file sharing, web, and competition traffic; do not lock out remote administration.
    3. Review active listeners, network shares, Bluetooth, and connection sharing; disable only unneeded exposure.
    4. Check DNS, routes, proxies, and /etc/hosts for unauthorized changes.
  5. Remote access and services
    1. Review SSH configuration and authorized_keys if SSH is installed; disable root login when not required.
    2. Inventory running and enabled services; identify each service before stopping or disabling it.
    3. Check remote desktop, VNC, Samba, printing, web, and discovery services against image requirements.
    4. Inspect scheduled tasks, systemd timers, cron jobs, and startup applications for unauthorized entries.
  6. Desktop security and privacy
    1. Lock the screen automatically and require authentication to unlock when supported and required.
    2. Review screensaver, power, and session settings; disable unattended guest or auto-login access.
    3. Review browser security settings, saved credentials, extensions, and default homepage/search changes.
    4. Remove unauthorized remote-control tools and verify shared folders and removable-media behavior.
    5. Review desktop applets, extensions, panel launchers, and user autostart entries for unexpected items.
  7. AppArmor, permissions, and integrity
    1. Check AppArmor status; keep supported profiles active and investigate unexpected profile changes.
    2. Verify ownership and permissions of /etc/passwd, /etc/shadow, /etc/group, and /etc/sudoers.
    3. Review SUID/SGID files, world-writable directories, home folders, and SSH permissions for unauthorized changes.
    4. Do not apply blanket recursive chmod/chown commands or remove package-owned files without investigation.
  8. Malware, logs, and persistence
    1. Review running processes, network listeners, shell profiles, cron, systemd units, and user autostart files.
    2. Check authentication, system, package, and application logs for unknown logins or unexpected changes.
    3. Inspect suspicious files before removal; preserve relevant evidence and avoid unknown cleanup scripts.
    4. Check time synchronization and confirm logs remain available and protected.
  9. Final verification
    1. Verify a required user can log in and elevate privileges only as authorized.
    2. Recheck firewall status, required services, network access, and competition-specific scoring requirements.
    3. Restart only when appropriate, then confirm the desktop, drivers, applications, and security settings remain functional.
    4. Record unresolved findings and revisit the README before any high-impact change.
  10. Quick commands
    1. cat /etc/linuxmint/info
    2. cat /etc/os-release
    3. id
    4. getent passwd
    5. getent group sudo
    6. sudo -l
    7. apt list --upgradable
    8. systemctl --type=service --state=running
    9. ss -tulpn
    10. sudo ufw status verbose
    11. sudo aa-status
    12. sudo journalctl -p warning -b
    13. systemctl list-timers
    14. find ~ -maxdepth 3 -type f -path '*/.config/autostart/*'
