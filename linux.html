Linux Checklist

DO NOT PROCEED WITHOUT INVESTIGATING THE FORENSICS QUESTIONS AND THE README FILE.

  1. Users & Groups
    1. Review getent passwd.
    2. Review sudo group.
    3. Remove or disable unauthorized accounts only if README permits.
  2. Updates
    1. sudo apt update
    2. sudo apt full-upgrade
  3. Services
    1. Review systemctl services.
    2. Disable unnecessary services only after confirming they are not required.
    3. Check SSH, Apache, Samba, FTP, Docker.
  4. SSH
    1. Inspect /etc/ssh/sshd_config.
    2. Disable root login unless required.
  5. Firewall
    1. Check ufw status.
    2. Allow only required ports.
  6. Scheduled Tasks
    1. Review cron jobs and systemd timers.
  7. Malware
    1. ps aux
    2. ss -tulpn
    3. Review authorized_keys
    4. Inspect startup scripts.
  8. Permissions
    1. Review SUID/SGID binaries.
    2. Review world-writable files.
    3. Protect /etc/shadow.
  9. Logs
    1. Protect /etc/shadow.
  10. Quick Commands
    1. whoami
    2. hostnamectl
    3. uname -a
    4. id
    5. groups
    6. passwd
    7. systemctl
    8. journalctl
    9. ufw status
    10. find / -perm -4000 2>/dev/null
