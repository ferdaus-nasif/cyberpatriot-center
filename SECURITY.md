# Security Policy

## Supported Versions

We actively monitor and maintain security patches for the live production branch hosted on Vercel and Cloudflare Pages.

| Version | Supported          |
| ------- | ------------------ |
| v3.x    | :white_check_mark: |
| < 3.x   | :x:                |

## Reporting a Vulnerability

As an elite CyberPatriot squad (Independence High School Team 6 / SEAL Team Six), we take system integrity seriously. If you discover a security vulnerability, an exposed asset, or a configuration flaw in this v3 deployment, please do NOT open a public GitHub issue. 

Instead, please report the vulnerability privately by:
* Opening a private security advisory directly through this GitHub repository's "Security" tab.
* Contacting the Team Captain directly.

We will acknowledge your report within 48 hours and coordinate an immediate patch via our automated Vercel/Cloudflare deployment pipeline.
